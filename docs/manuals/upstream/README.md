# NIIMBOT community wiki (copy)

The wiki is built from [MultiMote/niimbot-wiki](https://github.com/MultiMote/niimbot-wiki) and its `docs/` tree is licensed [CC BY-SA 4.0](LICENSE), so this copy stays under the same licence. The files are unmodified except for one change: [firmware/flashing-firmware.md](firmware/flashing-firmware.md) drops the footnote that credited its Python script to a comment on a third-party project's issue tracker.
